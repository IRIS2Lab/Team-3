# Multispectral RGB–LWIR Turret System

This repository contains code developed as part of a research project on adaptive RGB–LWIR sensor fusion for object detection and tracking under variable illumination.

The system combines RGB and thermal imagery with server-based object detection to evaluate detection confidence and tracking performance across different fusion levels.

## Dataset
The dataset used in this work is hosted on Zenodo.
**Zenodo dataset:** https://doi.org/10.5281/zenodo.18020084
